説明すること：
- 開業：資本金を記帳し、物件を借り上げる：資本金を現金出納帳に記帳する（ア 資本金）／棟カード（郊外・8室）を借り上げる。借上げ賃料は空室でも、借りている間ずっとかかる（時間で積み立て、自分の手番で払う）／物件を「持つ」のではなく「借りて貸す」商売。会社の資産は家具家電だけ
- 意思決定：家具家電を8セット買う：家具家電を置いた部屋が「募集中」になる／家具家電は資産（エ 家具家電）。毎期、減価償却する
- 意思決定：学生の入居契約（2室）：学生は春だけ：各期の自分の手番の2回目まで／家賃は相場−5で固定。期末に半分が卒業で退去する／入居1室ごとに入居費用 V（仲介・広告・清掃）がかかる
- 意思決定：法人の入居契約（3室）：法人は社宅需要。家賃は相場−1、法人枠の範囲で入れられる／法人は単価交渉をしてくる：サイコロを振り、4・5・6の目なら家賃がさらに1・2・3下がる。法人営業チップ1枚ごとに下げ幅を1抑えられる（今回は講師が振って2の目＝下がらない）／退去が少なく（10%）安定するが、大口法人の解約が来ると、法人がいちばん多い棟の法人が全員出ていく（同数なら先に借りた棟）／1回の入居契約で入れられる室数＝営業能力（営業スタッフの人数で決まる）。値引きを抑えるのは法人との関係（法人営業チップ）
- 意思決定：個人市場の入札（練習・2室）：親が「○室貸します」と宣言 → 参加者が家賃を伏せて出す → 安い順に入居／今回は練習なので、全員が家賃43で2室入居する（第2期からは本当の入札）／個人は家賃が高いが、期末に20%が退去する
- リスクカード：漏水・設備故障：リスクカードを引いたら、その手番は意思決定ができない／修繕費10（築古の棟は倍）。保険に入っていれば補償される
- 意思決定：保険に加入する：保険チップ1枚5。次の災害・設備故障を1回補償する
- チャンスカード：外国人材の受け入れ増：この期の法人枠が＋3になる。チャンスカードもその手番は意思決定ができない
- 意思決定：法人の入居契約（1室）：増えた法人枠で、最後の空室を埋める。これで満室／今回のサイコロは5の目：家賃が2下がる（法人営業チップが1枚あれば1で済む）
- 意思決定：営業スタッフを1人採用する：採用費5。給料は期末に、在籍している全員分を払う／営業が増えると1回の入居契約の室数が増える。管理スタッフは管理できる室数（1人12室）を決める／棟を増やす前に、人を増やしておく必要がある
- ルールB（説明だけ）：借入：第2期から。純資産の範囲で借りられ、借りるときに金利を前払いする／家賃の見直し・借上げの中途解約・配置転換・広告・法人営業・リノベ・スマートロック／借上げ賃料の減額交渉：第3期の期首だけ（サイコロ）
- 期末処理と決算：借上げ賃料と家賃を精算し、給料・本社家賃を払う／退去判定：棟ごとにサイコロを振り、出た目の半分（切り捨て）の室数が退去する。学生 → 個人 → 法人 の順に出ていく（今回は講師が振って4の目＝2室。学生2室が卒業）／空いた部屋は募集中に戻り、原状回復費がかかる／減価償却 → 決算（P/L・B/S）。入居率と損益分岐入居率を確かめる
