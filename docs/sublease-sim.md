# サブリース経営MG 数値シミュレーション（issue #104）

ルール作成・実装の前に、設計案（https://claude.ai/artifact/23T6G3k6jSxUC6Ki2DUQRx）の数値で
**4人・5人・6人の卓を各100ゲーム**自動で回し、ゲームとしても現実の事業としても成り立つ数値感を検証した。

- シミュレーター：`app/sim/sublease/`（製造業MGのコードは使っていない）
- 集計の全文：[設計案のまま](sublease-sim/result-base.md)／[調整後・行数制](sublease-sim/result-tuned.md)／[**時間制の案**](sublease-sim/result-time.md)

> **時間制＋第1期をルール説明の期にした案（11章）を本命とする。** 10章の時間制を土台に、第1期は全員が同じ動きをする（2026-10-07 の要望）。
>
> 以前の本命：**時間制の案（10章）**。 研修は時間制が多く（1期50〜60分・1手番1〜3分）、収入は自分の手番に入る形にしたい、という要望（2026-10-07）を受けて追加した。
> 4〜9章は行数制（設計案）での検証で、時間制の調整の土台になっている。

## 1. 前提（2026-10-07 に決定したこと）

- このサイトだけでゲームが完結する（紙の盤は使わない）
- 1卓4〜6人の順番制（反時計回り）。手番ごとに共有の山札（意思決定44・リスク10・チャンス6）から1枚引く
- 棟カードの市場（表向き3枚）と山札は卓で共有
- 個人市場はアプリ内の封印入札
- 退去判定は割合で固定（切り上げ）
- 目標：**第3期の終わりにぎりぎり黒字化**

## 2. 動かし方

```bash
cd app
node sim/sublease/run.mjs                      # 設計案のまま・4/5/6人 × 各100ゲーム
node sim/sublease/run.mjs --params tuned       # 調整後の数値（行数制）
node sim/sublease/run.mjs --params time        # 時間制の案
node sim/sublease/run.mjs --params tutorial    # 時間制＋第1期をルール説明の期にした案（本命）
node sim/sublease/tutorial-trace.mjs           # 第1期の台本を手番ごとにたどる（説明資料の元）
node sim/sublease/run.mjs --params tuned --brief 1                 # 人数ごとに1行の要約
node sim/sublease/run.mjs --params tuned --set '{"hq":30}'         # 数値を一時的に上書き
node sim/sublease/run.mjs --players 5 --games 300 --seed 7
```

乱数の種（`--seed`、既定 1）が同じなら結果も同じ。数値は `params.mjs`（`BASE`＝設計案、`TUNED`＝調整の差分、`TIME`＝時間制の差分。`time` は BASE に TUNED と TIME を重ねたもの）。

## 3. シミュレーションで再現したこと

| 項目 | 内容 |
|---|---|
| 手番 | 反時計回りに1枚ずつ引く。意思決定ならルールAを1つ、リスク・チャンスなら効果。親は期ごとに隣へ |
| 行数 | 第1期25行・第2期以降45行。手番・ルールB・**入札への参加（子）**で1行ずつ使う。誰かが使い切ったら、その周回で期末 |
| 物件 | 都市6・郊外10・地方8・築古4 の山札から表向き3枚。1棟8室・最大6棟 |
| 部屋 | 未準備 → 家具を買う → 募集準備（管理1人1回4室）→ 入居（法人・学生・個人の入札） |
| 個人の入札 | 親が室数を宣言 → 募集中の部屋がある他社が参加（1行使う）→ 全員が家賃を伏せて出す → 安い順に入居（リノベは2安く比べる） |
| 期首 | 継続家賃（入居中のプライスカードの合計）・法人税・期首の金利。第3期は借上げ賃料の減額交渉 |
| 期末 | 借上げ賃料・給料・本社家賃・返済・管理能力超過のクレーム・退去判定と原状回復・広告を1枚返す・減価償却・決算 |
| 決算 | G ＝ PQ − VQ − F。法人税は製造業MGと同じ式（30%・最低5）。毎期、貸借の一致を確かめている |
| 借入 | 製造業MGと同じ：第2期から・純資産×1倍まで・金利5%（借入時に前払い）・期末に残高×5%返済 |
| 資金ショート | 現金が足りなくなったら、借入枠があれば借り、なければ短期借入（金利10%）で埋めて「ショート」として数える |

### 自動プレイヤー（4つの性格）

最善手を探すものではなく、研修の参加者がとりそうな判断をしきい値で表したもの。席ごとにランダムに割り当てる。

| 性格 | 特徴 |
|---|---|
| 標準 standard | 入居が75%を超えたら次の棟。最大4棟。法人営業チップ1枚 |
| 積極 aggressive | 入居が50%で次の棟。最大6棟。入札で大きく値引き。借りてでも増やす |
| 堅実 steady | 入居90%で次の棟。最大3棟。法人営業チップ3枚・スマートロック・保険。借りない |
| 単価重視 premium | 個人を先に埋める。入札で値引きしない。リノベをする |

どの性格も「空室を埋める → 家具を置く → 家具を買う → 能力を足す → 棟を増やす」の順に考え、
期末に払う借上げ賃料・給料を見込んで現金を残す。棟を増やすときは、卓の個人の入居希望者の残りも見る
（アプリの市場ボードに出す前提）。

## 4. 設計案の数値のままだと

| 人数 | 経常利益 G の中央値（第1〜5期） | 第3期の黒字の会社 | 入居率 | 資金ショート（30以上） |
|---|---|---|---|---|
| 4人 | −133 / −115 / −122 / −125 / −113 | 8% | 50% | 74% |
| 5人 | −138 / −115 / −125 / −128 / −115 | 7% | 47% | 80% |
| 6人 | −134 / −116 / −123 / −135 / −122 | 6% | 49% | 81% |

**5期を通してほぼ全社が赤字で、ゲームとして成り立たない。** 原因は次の4つ。

1. **リスクカードが重すぎる**：1人が1期に約40枚引くので、山札（60枚）が1期に何周もする。1枚しかない「施工不備（全員退去＋入居停止）」でも1社あたり1期に約0.7回当たる。
   第3期の減額交渉の失敗（その期ずっと入居停止）も、1棟しかない会社は1期まるごと売上ゼロになる。
2. **期の途中の入居・退去の家賃が不自然**：入居時に1年分を受け取り、途中で出ていっても返さないので、空いた部屋に次の人を入れるとまた1年分入る。期の終わりの駆け込み入居でも1年分入る。
3. **1室の粗利が薄い**：相場45・借上げ28 でも、入札・法人（−2）・学生（−5）で実際の家賃は平均41前後。人件費・家具の償却・本社家賃を足すと、全室埋めてもほとんど利益が残らない。
4. **第1期が空っぽから始まる**：家具なし・入居者なしの1棟から始まり、第1期の半分以上が準備に消える。第1期は借入できないので、期末の借上げ賃料で資金がショートする。

## 5. 調整した数値

| 項目 | 設計案 | 調整後 | 理由 |
|---|---|---|---|
| 新規入居の家賃 | 入居時に1期分 | **入居した四半期から期末までの分**（按分） | 駆け込み入居で1期分入るのを防ぐ。四半期は「その会社が出納帳を何行使ったか」の1/4ずつで決める（アプリが自動で計算） |
| 期の途中の退去 | 返金なし | **いまの四半期から期末までの家賃を返す** | 同じ期間の家賃が二重に入るのを防ぐ |
| 新しく借りた棟の借上げ賃料 | 期末に1期分 | **借りた四半期から期末までの分** | 家賃と同じ考え方（実際のサブリースも契約月から払う） |
| 開始時の物件 | 郊外1棟・家具なし・空室 | **郊外1棟・家具8セット設置済み・法人2室＋個人5室が入居中** | 既存事業の引き継ぎから始める。第1期の継続家賃が入る。家具は資本金300の一部（現金204＋家具96） |
| 借上げ賃料（1室・1期） | 都市32・郊外28・地方24 | **都市28・郊外24・地方20** | 1室の粗利を厚くし、第3期に黒字化できるようにする |
| 相場家賃 | 都市50・郊外45・地方40 | 変えない | |
| 給料 | 25→28→31→34→37 | **25→27→29→31→33** | 上がり方を緩やかに |
| 法人枠の基本 | 1期2室 | **1期3室** | 法人比率を現実（レオパレス64.6%）に近づける。法人営業チップを買う性格だけが勝つ状態をなくす |
| 個人の期末の退去率 | 25% | **20%** | |
| 個人の入居希望者 | 上限なし | **卓で共有：1期あたり 人数×5人（6人卓は×6人）** | 需要に上限がないと入居率が常に100%近くになり、空室との戦いにならない。棟を増やしすぎると埋まらない |
| リスクカード | 設計案どおり | **施工不備：その棟の入居者の半分が退去＋改修費30（入居停止なし）／オーナー訴訟：費用20だけ／家賃の滞納：2枚→1枚** | 山札が1期に何周もする前提に合わせる |
| 減額交渉の失敗 | 費用20＋次の期まで入居停止 | **費用20だけ** | 同上 |

変えていないもの：資本金300、行数（25・45）、家具12（償却3）、V＝4、原状回復2、本社家賃25、チップ単価、学生（4室・相場−5）、法人の退去10%・学生50%、借入（第2期から・純資産×1倍）。

## 7. ゲームとして・現実として成り立つか

成り立つと判断した点：

- **固定費の重さが体験できる**：損益分岐入居率は第3期で約95%、第5期で約87%。入居率が数ポイント落ちるだけで赤字になる。
  レオパレスも入居率85%前後に対して損益分岐80%前後で、余裕が5ポイントほどしかない点は同じ。
- **戦略で結果が変わる**：「堅実に3棟を埋めきる」と「借りてでも6棟まで増やす」のどちらも1位になりうる。積極は当たれば一番伸びるが、資金ショートが6割（ハイリスク・ハイリターン）。
- **人数で不公平が出ない**：個人の入居希望者を人数に比例させ、6人卓だけ少し多くしたので、4〜6人で同じ形になる。
- **法人・個人・学生の性格が出る**：法人比率は期を追って33%→46%。法人は安定・低単価、個人は入札で取り合い（入札額の中央値41。相場より数単位安く入居する）。

気になる点（ルール作成で決めたい）：

- **入札で高く出すと勝てない**：単価重視（値引きしない・リノベ）は1位率が1割前後。封印入札は安い順なので、値引きしない会社は個人を取れない。
  「入札の同額はリノベが勝つ」以外に、高単価で入居させる道（例：リノベの棟は相場＋3まで入札できる、を強めに効かせる）が要るか。
- **入居率が高く出やすい**：時間で重みづけした入居率は92〜98%。自動プレイヤーは入居希望者の残りを見て棟を増やすので、空室が長く残りにくい。人が遊ぶと見込み違いで空室が増え、もう少し下がるはず。
- **資金ショートが2割**：大半は積極・単価重視。期末に数単位だけ足りない小さな不足も多いので、アプリでは「期末の支払い見込み」と「いまの現金」を常に並べて出し、足りないときの扱い（自動の短期借入・金利10%）をルールに書く。

## 8. ルールに反映したいこと（#90 の仕様書で決める）

1. 家賃・借上げ賃料の四半期按分（アプリが自動で計算。紙では大変だが、このサイトだけで遊ぶので可能）
2. 開始時の物件は「営業中」（家具8セット・法人2室・個人5室）
3. 上の表の数値（借上げ賃料・給料・法人枠・退去率・個人の入居希望者・リスクカードの重さ）
4. 期末に現金が足りないときの扱い（短期借入・金利10%）
5. 個人の入札で高単価を取る手段（単価重視の戦略を成り立たせるか）
6. 未決のまま残っているもの：1期の長さ（行数のままか時間制限も入れるか）、開発事業は入れない、外国人材は法人市場の一部（チャンスカード）

## 9. このシミュレーションの限界

- 自動プレイヤーは単純なしきい値で動く。人はもっと賢くも、もっと大胆にも動くので、実際の分布はもっと広がる
- ルールBの「家賃の見直し」「借上げの中途解約」「配置転換」は自動プレイヤーが使っていない
- 1期の長さは行数だけで決めている（時間制限は入れていない）
- 入札の駆け引き（相手の出方を読む）は、空室の多さと参加者数による値引きで近似している

## 10. 時間制の案（本命）

### 要望（2026-10-07）

- 研修は時間制が多い。1期は約50分〜1時間、1人の1手番は1〜3分
- 収入は自分の手番が来たときに入る
- 初期の資本金は「1棟を充実させる」か「2棟にまんべんなく」かを選べる額にしたい

### 時間制で分かったこと

1手番1〜3分だと、**1人が1期に打てる手番は約5〜7回**しかない（行数制の25〜45行の1/5〜1/7）。
設計案の動き方（家具を買う → 募集準備 → 2室ずつ入居）のままだと、第1期は準備で終わり、5期を通して赤字だった。
また人数が多い卓ほど1人あたりの手番が減る（4人卓 6.3回・6人卓 5.1回／55分）ので、**1期の時間を人数に比例させて、1人あたりの手番をそろえる**と、どの人数でも同じ形になる。

### 時間制のルール（シミュレーションしたもの）

| 項目 | 内容 |
|---|---|
| 1期の時間 | **4人卓45分・5人卓55分・6人卓65分**（約11分×人数。1人1期あたり約5.5〜5.7手番）。時間が来たら、その周回を終えて期末 |
| 1手番 | 1〜3分（個人の入札があった手番は＋1分） |
| 収入（家賃） | 入居中の部屋の家賃を「経過時間 ÷ 1期の時間」で積み立て、**自分の手番が来たときにまとめて受け取る**。期末に残りを精算 |
| 借上げ賃料 | 家賃と同じく時間で積み立て、自分の手番で払う（期末にまとめて払うより、空室の痛みが毎手番見える） |
| 時間で数える理由 | 手番の回数ではなく時間で数えるので、1期まるごと入居していれば、手番が何回でもちょうど1期分の家賃になる。人数や手番の速さで不公平が出ない。按分の計算はアプリがする |
| 開業準備 | 第1期の時計を動かす前に、資本金で棟を借りて家具を入れる（**1棟に家具8セット**か、**2棟に4セットずつ**）。席順に表向きの棟カードから選ぶ |
| 家具 | 買ったらその場で部屋に置く（購入と募集準備を1回にまとめる）。棟を借りる手番で、その棟の家具も一緒に買える |
| 入居契約 | 営業1人で1回**6室**まで（行数制は2室）。法人枠の基本 **6室**／期、個人の入居希望者は卓で1人あたり**10人**／期 |
| 借上げ賃料 | **都市27・郊外23・地方19**（設計案から−5） |
| その他 | 資本金 **500**、本社家賃 **15**、給料 25→27→29→31→33、個人の退去20%、リスクカードは軽い版 |

### 結果（各100ゲーム）

| 人数 | 1人の手番／期 | G の中央値（第1〜5期） | 第3期の黒字 | 第3期の入居率 | 損益分岐入居率 | 資金ショート（30以上） | 第5期末の純資産 |
|---|---|---|---|---|---|---|---|
| 4人（45分） | 5.7 | −201 / −47 / **+12** / +58 / +168 | 59% | 84% | 84% | 6% | 442 |
| 5人（55分） | 5.7 | −217 / −41 / **+6** / +56 / +150 | 54% | 83% | 85% | 7% | 422 |
| 6人（65分） | 5.5 | −209 / −47 / **+9** / +49 / +149 | 54% | 83% | 85% | 10% | 431 |

- **第3期の中央値 +6〜+12**、黒字の会社が5割強で、4〜6人とも同じ形
- **入居率83〜84%・損益分岐入居率84〜85%**：レオパレス（入居率85%前後・損益分岐80%前後）に近い。行数制の調整案（入居率95%）より現実的
- 資金ショート（30以上）は6〜10%（行数制の調整案は約20%）。手番ごとに家賃が入り借上げ賃料を払うので、期末にまとめて足りなくなることが減った
- 第1期は約−200と大きな赤字（開業直後は空室のまま借上げ賃料がかかる）。資本金500はこれを乗り切れる額

### 開業の方針（1棟を充実／2棟にまんべんなく）

| 資本金 | 1棟を充実：第1期 G | 2棟にまんべんなく：第1期 G | 1位になった割合（1棟／2棟） | 資金ショート（どこかの期） |
|---|---|---|---|---|
| 450 | −155 | −275 | 63% ／ 37% | 25〜31% |
| **500** | −155 | −280 | 65% ／ 35% | 16〜19% |
| 600 | −155 | −280 | 64% ／ 36% | 7〜12% |

- 資本金500なら**どちらの方針も成り立つ**（2棟でも資金ショートが大きく増えない）。1位になるのは1棟が3分の2、2棟が3分の1

### 時間制でルールに反映したいこと

1. 1期の時間を人数に比例させる（45／55／65分）か、50〜60分の範囲に収めて人数による差を受け入れるか
   （同じ数値で、55分固定だと第3期の G 中央値は 4人卓 +48・5人卓 +6・6人卓 −6、

3. 開業準備（時計を動かす前に棟と家具を選ぶ）と資本金500

## 12. 法人の扱い（2026-10-07 の決定）

法人は「安定するが単価が低い」だけで、リスクが軽すぎた（法人営業チップを多く買う堅実な性格が一番勝っていた）。現実の法人契約のリスク（集中・値下げ圧力）を入れる。

| 項目 | 以前 | 決定 | 現実との対応 |
|---|---|---|---|
| 大口法人の解約（リスクカード） | 法人の入居者を2室まで外す | **法人の入居者がいちばん多い棟の法人を全員解約**（同数なら先に借りた棟） | 法人に偏った棟ほど一度に崩れる（集中リスク）。どの部屋が対象か迷わない |
| 法人の家賃 | 相場−2で固定 | **相場−1 ＋ 単価交渉のサイコロ** | 法人はまとまった数を契約する代わりに値引きを求める |
| 単価交渉 | なし | 法人の入居契約のたびにサイコロ。**4・5・6の目で家賃が1・2・3下がる**（1〜3は下がらない）。**法人営業チップ1枚ごとに下げ幅−1** | 値引き交渉を左右するのは法人との関係の深さ（窓口・取引実績） |

- 1回の入居契約に1回振り、その契約で入れた法人の部屋すべてに同じ下げ幅をかける
- 第1期の台本では講師が振った目を全員で使う（手番3は2の目＝下がらない、手番8は5の目＝2下がる）

| 以前（解約2室・相場−2・サイコロなし） | +12 ／ +5 ／ −2 | − | 37〜41% |
| 解約3分の1だけ | +12 ／ +3 ／ −1 | − | 35〜42% |
| 解約3分の1 ＋ 相場−2 ＋ サイコロ（抑えなし） | +4 ／ −4 ／ −5 | 1.0 | 36〜39% |

## 13. 期末の退去は棟ごとのサイコロ（2026-10-07 決定）

以前の「種類ごとに 入居室数 × 退去率 を切り上げ」は、入居が少ないと実際の退去率が名目よりずっと高くなる（法人1室だけだと毎期必ず退去）うえ、
現実の目安（単身の平均居住は約3年＝年3割前後、学生は4年制なら年2.5割前後）からも外れていた。そこで次のようにした。

- 期末に**棟ごとにサイコロを振り、出た目の半分（切り捨て）の室数が退去**する（1→0・2,3→1・4,5→2・6→3）
- 出ていく順は **学生 → 個人 → 法人**（学生は卒業で出やすく、法人は会社が契約を続けるので出にくい）
- 満室の棟で平均約1.5室（約19%）。期ごとに山谷が出る
- 第1期の台本では講師が振った目を全員で使う（4の目＝2室。学生2室が卒業）

| 案 | 1棟あたりの平均退去 | 第3期 G | 資金ショート（どこかの期） |
|---|---|---|---|
| 以前（割合・切り上げ） | 約1.8室 | +9 ／ +4 ／ +4 | 6〜11% |
| 出た目の人数そのまま | 3.5室 | −44 ／ −56 ／ −43 | 28〜30% |
| 出た目の半分（切り捨て） | 1.5室 | +30 ／ +29 ／ +19 | 4〜6% |

- 出た目の人数そのままは1棟の4割以上が毎期出ていき、現実より多すぎる
- 採用した案は、性格ごとの1位率も 標準49%・積極44%・堅実35% と偏りが小さくなった
- 期ごとの山谷：第3期の赤字は43〜48%、第4期でも19〜25%の会社が前の期より利益が下がる。毎期増益の会社は約半分

## 14. 退去する入居者をプレイヤーが選べる場合（2026-10-07 の検証）

退去する**室数**は13章のサイコロで決まり、**誰が出ていくか**を各社が選ぶ場合を試した（`--set '{"evictChoose":"player"}'`）。
第1期の台本は全員同じ盤面にするため、選ばずに決まった順（学生 → 個人 → 法人）のまま。

自動プレイヤーの選び方：標準・積極・単価重視は**家賃の安い部屋から**出す（来期の継続家賃をできるだけ残す）。堅実は**法人を残す**（学生 → 個人の順）。同じ家賃なら学生から出す（次の春にまた入れられる）。

### 結果（各100ゲーム・第3期の G 中央値 4人／5人／6人）

| 誰が出ていくか | 第3期 G | 第5期 G | 第3期の黒字 | 1位（標準／積極／堅実） |
|---|---|---|---|---|
| 固定の順番（学生 → 個人 → 法人）＝今の案 | +15 ／ +11 ／ +5 | +143 ／ +137 ／ +137 | 53〜57% | 35〜38% ／ 20〜34% ／ 27〜41% |
| **各社が選ぶ** | **+16 ／ +14 ／ +9** | +149 ／ +145 ／ +150 | 55〜59% | 31〜37% ／ 19〜37% ／ 25〜42% |
| くじ（比較用） | +10 ／ +7 ／ +6 | +144 ／ +129 ／ +132 | 54〜56% | − |

- 選べると、第3期で数単位、第5期で10前後利益が増える。上手に選ぶ（家賃の安い人から出す）とくじより1期あたり5〜7くらい得
- 差が小さいのは、入居者ごとの家賃の差が小さいため（法人は相場−1〜−4、学生は相場−5、個人は入札でだいたい40〜45）
- 勝ち方の偏り・第3期のぎりぎり黒字はほとんど変わらない（数値を直さなくても成り立つ）

### 決定（2026-10-07）

**固定の順番（学生 → 個人 → 法人）にする。** 選べるようにしても判断の深さは小さく、現実（出ていくかは入居者が決める）から離れ、期末の時間も延びるため。
`params.mjs` の `evictChoose` は `'order'`（既定）のまま。比べた材料は下の表。

| | 固定の順番 | 各社が選ぶ |
|---|---|---|
| 現実との近さ | 近い（出ていくかは入居者が決める。学生は卒業、法人は残りやすい） | 遠い（会社が出ていく人を選ぶことは本来ない）。「契約更新の条件交渉で、どの部屋の更新を優先するか」と説明すれば成り立つ |
| 判断の深さ | なし | 少しある（安い家賃の部屋・学生から出す、法人を残す） |
| 時間 | 期末が早い | 棟ごとに選ぶので、期末に少し時間がかかる（アプリで「おすすめ：家賃の安い順」を出せば短くできる） |

### 管理能力を超えた入居の退去も同じ順番に（2026-10-07 決定）

期末に入居が管理能力（管理スタッフ×12室＋スマートロック×6室）を超えていたら、超えた分が退去してクレーム費用5／室がかかる。
この退去の順番も、退去のサイコロと同じ **学生 → 個人 → 法人** にそろえた（以前は個人 → 学生 → 法人）。覚える順番を1つにするため。
管理能力の超過は自動プレイヤーではほとんど起きない（クレーム費用は1期あたり平均1〜2）ので、結果の数値はほぼ変わらない。

### 物件の借り上げは記帳の最初の手番に（2026-10-07 決定）

開業（期首処理）では資本金を記帳するだけにし、**物件の借り上げは第1期の記帳の手番1（意思決定・ルールA）**で行う（物件の借り上げもルールとして体験するため）。
学生は「自分の手番の2回目まで」なので、借り上げと家具を別の手番にすると学生が3回目になる。そこで手番1で「物件を借り上げる ＋ 同じ手番で家具8セット」を行う。
借上げ賃料がかかり始めるのが少し遅くなり、第1期の G は −84 → −76、第2期の期首の現金は 252・純資産 319 になった（第3期の G 中央値は +12／+10／+4）。

### 入居者の種類に特化した場合（2026-10-07）

② 法人の半分・個人＝出た目・借上げ賃料−4 で、入札で取りにいく種類だけが違う4つの戦い方を卓に混ぜた（棟の増やし方・採用などは標準と同じ）。

|---|---|---|---|---|---|
